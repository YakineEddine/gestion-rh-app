# Règle Git — Commit et Push systématiques

À la fin de chaque tâche ou évolution demandée par l'utilisateur :
1. Toujours vérifier l'état du dépôt (`git status`).
2. Ajouter et commiter systématiquement les modifications avec un message clair et conventionnel (`git add ...`, `git commit -m "..."`).
3. Effectuer immédiatement le push vers le dépôt distant GitHub (`git push origin main`).
